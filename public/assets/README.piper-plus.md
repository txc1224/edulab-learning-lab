# Piper Plus 中文字典

这两个 JSON 文件来自 [Piper Plus](https://github.com/ayutaz/piper-plus) 的中文音素资源，供浏览器内的 Rust WASM 音素器使用。

应用使用的语音模型是 [ayousanz/piper-plus-tsukuyomi-chan](https://huggingface.co/ayousanz/piper-plus-tsukuyomi-chan)。模型语音使用つくよみちゃんコーパス，使用时请遵守其[素材使用条款](https://tyc.rei-yumesaki.net/material/corpus/#terms3)。
